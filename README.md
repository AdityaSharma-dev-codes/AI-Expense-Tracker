# AI Expense Tracker

## 📌 Project Overview
AI Expense Tracker is an **offline academic project** designed to help users track, categorize, and analyze their expenses efficiently.  
The system integrates basic AI-driven insights to improve expense understanding while maintaining a simple and user-friendly interface.

This project was developed as part of a **team-based academic assignment**, with clear separation of responsibilities among team members.
